# 泥峭铭文板

## 基本信息
- **物品ID**: `bluff_tablet`
- **标签**: #特殊 #魔法

## 被动效果

当配合泥峭核心食用泥土时：
- 每个铭文板提供2点吸收效果
- 最大吸收值 = 泥峭器官数量 × 8
- 吸收效果持续直到受到伤害

## 配合效果
- 与泥峭核心和活性泥峭棒配合使用
- 共享最大吸收值计算
