## 设计概述

### 核心设计理念

肿瘤系统的平衡性设计围绕**"风险与收益的动态平衡"**展开。平衡不是静态的数值对等，而是：
- **可预测的风险** - 玩家能够理解并评估风险
- **可控的代价** - 通过策略可以降低风险
- **多元的收益** - 不同策略有不同价值
- **动态的平衡** - 随游戏进程调整平衡点

### 设计原则

1. **高风险高回报，而非纯负面** - 肿瘤应该是可选项，而非强制
2. **提供策略空间** - 多种有效的玩法路径
3. **避免极端情况** - 防止过强或过弱的极端Build
4. **保持游戏乐趣** - 平衡性不应牺牲游戏性
5. **渐进式复杂度** - 新手易上手，大师有深度

### 平衡性目标

| 维度 | 目标 | 指标 |
|------|------|------|
| **强度平衡** | 肿瘤Build vs 非肿瘤Build | 胜率差异<10% |
| **类型平衡** | 良性/恶性/特殊肿瘤 | 使用率差异<30% |
| **策略多样性** | 有效Build数量 | 至少5种主流Build |
| **游戏体验** | 玩家满意度 | >70%正面反馈 |
| **性能影响** | FPS和内存占用 | <5%性能下降 |

## 风险-收益平衡系统

### 风险-收益曲线设计

#### 肿瘤数量与收益曲线

```
收益曲线（正向）:
0个肿瘤: 基准线（0%）
1个肿瘤: +15% 综合实力
2个肿瘤: +30% 综合实力
3个肿瘤: +45% 综合实力
4个肿瘤: +55% 综合实力（边际收益递减）
5个肿瘤: +65% 综合实力
6个肿瘤: +70% 综合实力（明显递减）
7个肿瘤: +75% 综合实力
8个肿瘤: +78% 综合实力（几乎递减）
9个肿瘤: +80% 综合实力（上限）

风险曲线（负向）:
0个肿瘤: 0% 风险
1个肿瘤: +5% 风险（可控）
2个肿瘤: +10% 风险
3个肿瘤: +18% 风险（开始递增）
4个肿瘤: +25% 风险
5个肿瘤: +35% 风险（加速递增）
6个肿瘤: +45% 风险
7个肿瘤: +55% 风险（高风险）
8个肿瘤: +65% 风险
9个肿瘤: +75% 风险（极高风险）
```

**净收益曲线**（收益-风险）:
- 1-3个肿瘤: 净收益递增（+10%→+20%→+27%）
- 4-6个肿瘤: 净收益持平（+30%→+30%→+25%）
- 7-9个肿瘤: 净收益递减（+20%→+13%→+5%）

**设计意图**: 鼓励中等数量的肿瘤使用（3-6个），而非极端的全肿瘤或零肿瘤。

#### 不同类型肿瘤的风险差异

##### 良性肿瘤风险曲线

**特征**: 低风险、稳定收益、可预测

| 数量 | 收益 | 风险 | 净收益 | 风险类型 |
|------|------|------|--------|----------|
| 1个 | +12% | +3% | +9% | 饥饿/环境弱点 |
| 2个 | +22% | +6% | +16% | 副作用叠加 |
| 3个 | +30% | +10% | +20% | 多弱点并存 |
| 4+个 | +35% | +15% | +20% | 饱和效应 |

**风险特点**:
- ✅ 可预测: 副作用明确，可提前准备
- ✅ 可控制: 通过物品和策略可缓解
- ✅ 累积慢: 风险增长缓慢
- ❌ 收益上限: 净收益难以超过+25%

##### 恶性肿瘤风险曲线

**特征**: 高风险、高收益、不稳定

| 数量 | 收益 | 风险 | 净收益 | 风险类型 |
|------|------|------|--------|----------|
| 1个 | +18% | +8% | +10% | 随机负面 |
| 2个 | +35% | +18% | +17% | 层数积累 |
| 3个 | +50% | +30% | +20% | 狂暴风险 |
| 4个 | +60% | +45% | +15% | 高风险区 |
| 5+个 | +65% | +60% | +5% | 极端风险 |

**风险特点**:
- ⚠️ 不可预测: 随机触发，无法完全控制
- ⚠️ 快速累积: 层数系统导致风险加速
- ⚠️ 爆发式: 可能突然触发严重后果
- ✅ 高上限: 理论上可达到+70%收益（但风险极高）

##### 特殊肿瘤风险曲线

**特征**: 极端随机、极端收益或极端风险

| 数量 | 收益 | 风险 | 净收益 | 风险类型 |
|------|------|------|--------|----------|
| 1个 | +25% | +12% | +13% | 彩票机制 |
| 2个 | +50% | +40% | +10% | 双重彩票 |
| 3+个 | +70% | +70% | 0% | 完全随机 |

**风险特点**:
- 🎲 完全随机: 可能极强，也可能极弱
- 🎲 两极分化: 最佳情况+50%，最差情况-30%
- 🎲 状态循环: 持续变化，无法稳定
- ❌ 不可控: 几乎无法通过策略影响

### 高收益搭配的代价机制

#### 套餐搭配代价设计

**2件套餐 - 恶性生长**:
- **收益**: +30%最大生命值
- **代价**: -50%生命恢复
- **风险评级**: ★★☆☆☆
- **Mitigation**: 搭配恢复类器官（如九头蛇）

**4件套餐 - 狂暴突变**:
- **收益**: +50%所有伤害
- **代价**: 每秒1点生命流失，无法自然恢复
- **风险评级**: ★★★★☆
- **Mitigation**: 高伤害快速击杀敌人，吸血类装备

**6件套餐 - 肿瘤军团**:
- **收益**: 所有属性+20%，狂暴阈值40%
- **代价**: 生命恢复-30%，每30秒随机负面效果
- **风险评级**: ★★★★★
- **Mitigation**: 良性肿瘤混搭，降低整体风险

**9件套餐 - 不死之身**:
- **收益**: 死亡时60秒不死状态，期间+100%伤害和速度
- **代价**: 需要维持9个肿瘤器官的高风险，不死状态后虚弱5分钟
- **风险评级**: ★★★★★
- **Mitigation**: 不死状态期间快速结束战斗

#### 共生搭配代价设计

**增殖核心共生**（心脏+肺脏）:
- **收益**: 持续生命恢复+伤害输出
- **代价**: 每分钟增殖1个肿瘤器官（占用槽位）
- **风险**: 可能增殖到高风险区
- **Mitigation**: 准备移除工具，主动控制增殖

**净化系统共生**（肝脏+肾脏）:
- **收益**: 免疫所有毒素和负面效果
- **代价**: 毒素/废物层数达到上限时持续失血
- **风险**: 层数管理失误导致死亡
- **Mitigation**: 定期清除层数，监控层数UI

**狂暴战士共生**（心脏+肌肉）:
- **收益**: 狂暴阈值提升，期间大幅增伤
- **代价**: 肌肉痉挛概率无法降低
- **风险**: 关键时刻瘫痪导致死亡
- **Mitigation**: 保持较高血量，避免狂暴

### 避免强迫使用的平衡设计

#### 非肿瘤Build的竞争力

确保不使用肿瘤器官的玩家依然有竞争力:

**非肿瘤Build的优势**:
1. **稳定性**: 无随机副作用，表现稳定
2. **可预测**: 战斗结果可预测，适合策略型玩家
3. **低风险**: 不会因为随机性突然死亡
4. **多样性**: 其他器官类型有独特优势

**平衡机制**:
- 其他器官类型搭配效果略有提升（+5-10%）
- 肿瘤器官的副作用对非肿瘤玩家无影响
- 非肿瘤玩家在特定场景有优势（如长时间战斗）

#### 肿瘤的自愿性

**设计原则**: 肿瘤应该是"强力选项"，而非"必需品"

**实现方式**:
1. **获取可选**: 不强制玩家获取肿瘤器官
2. **移除容易**: 提供简单的移除方式
3. **替代方案**: 其他器官类型可以达成类似效果
4. **游戏进程**: 不影响主线游戏进度

### 过强搭配识别与调整

#### 潜在过强搭配

**1. 心脏+肌肉共生（狂暴战士）**
- **问题**: 低血量时伤害+100%（心脏50%+肌肉30%+肾上腺素50%）
- **调整**:
  - 肾上腺素从+50%降至+30%
  - 狂暴战士共生从+30%降至+20%
  - 调整后总伤害: +110% → +90%

**2. 肝脏6层+肾脏10层**
- **问题**: 伤害+80%（肝脏30%+肾脏50%），但有持续失血
- **调整**:
  - 肾脏10层从+50%降至+40%
  - 调整后总伤害: +80% → +70%
  - 增加层数衰减速度（从60秒/层降至45秒/层）

**3. 6件套餐+增殖机制**
- **问题**: 增殖度达到危险期（9+器官），风险失控
- **调整**:
  - 6件套餐不再触发自动增殖
  - 增殖需要玩家主动触发
  - 增殖度从12+失控降至13+失控

**4. 阑尾觉醒（完美适应）**
- **问题**: +50%所有器官效果，持续5分钟
- **调整**:
  - 觉醒概率从5%降至3%
  - 完美适应从+50%降至+40%
  - 持续时间从5分钟降至3分钟

### 过弱搭配增强

#### 潜在过弱搭配

**1. 肠子单独使用**
- **问题**: +1 HEALTH，收益太低
- **增强**:
  - 基础属性从+1 HEALTH提升至+2 HEALTH
  - 添加被动效果: 生命恢复+20%

**2. 阑尾觉醒失败（阑尾炎）**
- **问题**: 95%概率失败，挫败感强
- **调整**:
  - 失败概率从95%降至85%
  - 阑尾炎伤害从1点/秒降至0.5点/秒
  - 添加"觉醒尝试次数"统计，10次尝试后必定觉醒一次

**3. 肾脏过滤超载负面期**
- **问题**: 10秒属性-10%太长
- **调整**:
  - 负面持续时间从10秒降至7秒
  - 爆发期从5秒延长至6秒

**4. 脾脏脆弱防线**
- **问题**: 10%概率额外50%受伤过于致命
- **调整**:
  - 概率从10%降至7%
  - 额外受伤从50%降至40%

## 玩家策略空间

### 多样化Build设计

#### Build类型分类

**1. 稳定发育Build（良性为主）**

**核心器官**: 胃、肺脏、脾脏
**特点**: 可预测、低风险、稳定发育
**适用场景**: 前期发育、探索、长期战斗
**优势**:
- 副作用可控
- 不会突然死亡
- 适合新手

**劣势**:
- 收益上限低（+30-40%）
- 缺乏爆发能力
- 长期战斗乏力

**典型搭配**:
- 胃+肺脏: 毒素扩散
- 肺脏+脾脏: 环境适应+免疫
- 3件良性套餐: 完美适应

**2. 狂暴爆发Build（恶性为主）**

**核心器官**: 心脏、肌肉、肝脏
**特点**: 高爆发、高风险、短时间战斗
**适用场景**: BOSS战、速通、PVP
**优势**:
- 极高的伤害输出（+80-100%）
- 爆发期几乎无敌
- 快速结束战斗

**劣势**:
- 随机性高，可能关键时刻瘫痪
- 长期战斗持续失血
- 需要高超的操作技巧

**典型搭配**:
- 心脏+肌肉: 狂暴战士
- 心脏+肝脏: 增殖爆发
- 4件恶性套餐: 侵蚀之主

**3. 赌徒运气Build（特殊为主）**

**核心器官**: 阑尾、肠子
**特点**: 完全随机、极端体验
**适用场景**: 娱乐、挑战、速通
**优势**:
- 最佳情况下极强（+100%+）
- 每次使用体验不同
- 娱乐性高

**劣势**:
- 最差情况下极弱（-30%）
- 完全不可控
- 不适合严肃游戏

**典型搭配**:
- 阑尾+肠子: 突变共鸣
- 阑尾尝试多次: 必定觉醒一次
- 阑尾觉醒后: 任何Build都变强

**4. 均衡混合Build（良性+恶性）**

**核心器官**: 心脏、胃、肾脏、脾脏

## 治疗与移除机制

### 移除机制设计

#### 基础移除方式

**手动移除**:
- **方式**: 在胸腔UI中右键点击肿瘤器官移除
- **代价**: 无
- **限制**: 只能在非战斗状态下移除
- **设计理由**: 允许玩家自由调整Build，无惩罚

**手术移除**（高级）:
- **方式**: 使用"手术刀"工具移除
- **代价**: 消耗手术刀，失去10%当前生命
- **优势**: 可以在战斗中移除（有风险）
- **设计理由**: 提供紧急情况下的移除方式

**批量移除**:
- **方式**: 使用"净化药水"
- **效果**: 移除所有肿瘤器官
- **代价**: 消耗稀有材料（如龙蛋、末影珍珠）
- **设计理由**: 一键清除，适合后悔的玩家

### 增殖器官处理

#### 自动增殖的器官

**问题**: 增殖机制可能产生多余的器官

**处理方式**:
1. **自动替换**: 增殖的新器官自动替换最弱的肿瘤器官
2. **手动选择**: 增殖时弹窗让玩家选择替换哪个器官
3. **临时器官**: 增殖的器官是临时的，5分钟后消失

**推荐方式**: 自动替换
- **优点**: 简单、自动
- **缺点**: 可能替换玩家想保留的器官
- **缓解**: 显示"增殖即将发生"提示，给玩家时间准备

### 治疗机制设计

#### 阑尾炎治疗

**自然消退**:
- **方式**: 等待阑尾炎自然结束
- **时间**: 10-60秒（随机）
- **风险**: 持续失血

**药物治疗**:
- **方式**: 使用"抗生素"药水
- **效果**: 立即治愈阑尾炎
- **代价**: 消耗抗生素（中 rarity）
- **设计理由**: 提供可控的治疗方式

**手术治疗**:
- **方式**: 移除阑尾器官
- **效果**: 立即治愈阑尾炎，但失去阑尾
- **代价**: 永久失去阑尾
- **设计理由**: 绝望时的选择

#### 毒素层数清除

**肝脏毒素**:
- **自然清除**: 每分钟-1层
- **加速清除**: 肝脏+肾脏共生（每分钟-2层）
- **立即清除**: 使用"解毒剂"（清除所有层）

**肾脏废物**:
- **自然清除**: 每分钟-1层
- **加速清除**: 肝脏+肾脏共生（每分钟-2层）
- **立即清除**: 使用"净化水晶"（清除所有层）

### 移除的代价与风险

#### 即时代价

**生命值损失**:
- 手术移除: -10%当前生命
- 净化药水: -20%当前生命（强制净化有代价）

**器官损失**:
- 手术切除阑尾: 永久失去阑尾
- 移除增殖器官: 失去增殖的收益

#### 长期代价

**属性损失**:
- 移除后失去肿瘤器官的属性加成
- 可能导致Build强度下降

**搭配失效**:
- 移除后可能不满足套装条件
- 需要重新调整Build

### 治疗与游戏机制交互

#### 与其他器官的交互

**九头蛇器官**:
- **交互**: 九头蛇的再生可以抵消肿瘤的副作用
- **平衡**: 合理的搭配，无问题

**九狱器官**:
- **交互**: 九狱的低血量高伤与肿瘤的狂暴机制协同
- **平衡**: 可能过强，需要监控

**弗兰肯斯坦器官**:
- **交互**: 弗兰肯斯坦的器官排斥与肿瘤的不稳定性叠加
- **平衡**: 高风险高收益，合理

#### 与游戏机制的交互

**死亡机制**:
- **死亡后**: 肿瘤器官保留（不掉落）
- **设计理由**: 避免死亡惩罚过重

**重生机制**:
- **重生后**: 所有层数（毒素、废物）重置
- **设计理由**: 给玩家"重置"机会

**维度传送**:
- **传送后**: 无影响
- **设计理由**: 避免跨维度问题

## 反滥用设计

### 防止过度利用漏洞

#### 增殖漏洞

**潜在漏洞**: 玩家可能利用增殖机制无限制生成器官

**防护措施**:
1. **增殖度上限**: 增殖度达到15+时，增殖概率降至0%
2. **增殖冷却**: 每次增殖后5分钟内无法再次增殖
3. **槽位限制**: 增殖不能超过胸腔剩余槽位
4. **器官质量上限**: 同种器官不能超过3个

**代码示例**:
```java
public boolean canProliferate(Player player, TumorData data) {
    // 检查增殖度
    if (data.getProliferationDegree() >= 15) {
        return false;
    }

    // 检查冷却
    if (data.getProliferationCooldown() > 0) {
        return false;
    }

    // 检查槽位
    ChestCavityData ccData = getChestCavityData(player);
    if (ccData.getEmptySlots() == 0) {
        return false;
    }

    // 检查器官数量
    if (data.getOrganCount(tumor_heart) >= 3) {
        return false;
    }

    return true;
}
```

#### 阑尾觉醒漏洞

**潜在漏洞**: 玩家可能通过频繁开关胸腔刷觉醒

**防护措施**:
1. **觉醒尝试限制**: 每小时最多尝试1次觉醒
2. **觉醒惩罚**: 连续失败3次后，下次失败阑尾炎持续时间+50%
3. **觉醒保底**: 10次尝试后必定觉醒1次

**代码示例**:
```java
public boolean canAttemptAwakening(Player player, TumorData data) {
    // 检查冷却
    long lastAttempt = data.getLastAppendixAttempt();
    long cooldown = 60 * 60 * 1000; // 1小时
    if (System.currentTimeMillis() - lastAttempt < cooldown) {
        return false;
    }

    return true;
}

public void onAppendixAttempt(Player player, boolean success) {
    TumorData data = getTumorData(player);
    data.setLastAppendixAttempt(System.currentTimeMillis());

    if (!success) {
        int consecutiveFails = data.getConsecutiveFails() + 1;
        data.setConsecutiveFails(consecutiveFails);

        // 惩罚机制
        if (consecutiveFails >= 3) {
            data.setAppendixInflammationDuration(
                data.getAppendixInflammationDuration() * 1.5f
            );
        }

        // 保底机制
        int totalAttempts = data.getTotalAttempts() + 1;
        data.setTotalAttempts(totalAttempts);
        if (totalAttempts >= 10) {
            data.setGuaranteedAwakening(true);
        }
    } else {
        data.setConsecutiveFails(0);
        data.setTotalAttempts(0);
        data.setGuaranteedAwakening(false);
    }
}
```

#### 搭配叠加漏洞

**潜在漏洞**: 玩家可能利用多种搭配叠加获得极端收益

**防护措施**:
1. **效果上限**: 设置总伤害上限（+200%）
2. **效果递减**: 相同类型的效果递减（第二个+50%，第三个+25%）
3. **负面效果不递减**: 负面效果不参与递减机制

**代码示例**:
```java
public float applyDamageModifiers(Player player, float baseDamage) {
    float totalBonus = 0.0f;
    List<DamageModifier> modifiers = getDamageModifiers(player);

    // 排序：从高到低
    modifiers.sort((a, b) -> Float.compare(b.bonus, a.bonus));

    // 应用递减
    for (int i = 0; i < modifiers.size(); i++) {
        DamageModifier mod = modifiers.get(i);
        float diminishedBonus = mod.bonus / (1 << i); // 50%递减
        totalBonus += diminishedBonus;
    }

    // 上限
    totalBonus = Math.min(totalBonus, 2.0f); // +200%上限

    return baseDamage * (1.0f + totalBonus);
}
```

### 限制极端策略

#### 全肿瘤Build

**问题**: 9件套餐"不死之身"可能过于强力

**限制措施**:
1. **高风险**: 维持9个肿瘤需要高超技巧
2. **不死代价**: 不死状态后虚弱5分钟（所有效果-50%）
3. **增殖失控**: 9个器官增殖度达到12+，可能失控
4. **移除困难**: 移除任何一个器官都可能导致连锁反应

#### 纯阑尾赌博

**问题**: 玩家可能只装备阑尾，反复尝试觉醒

**限制措施**:
1. **觉醒冷却**: 每小时最多1次尝试
2. **失败惩罚**: 阑尾炎伤害累积
3. **单一器官**: 阑尾单独装备收益极低（+1 HEALTH）

#### 无限增殖Build

**问题**: 利用增殖机制无限增殖

**限制措施**:
1. **增殖度上限**: 15+时增殖概率0%
2. **增殖失控**: 12+时每10秒失去1点生命，20%概率摧毁器官
3. **器官质量上限**: 同种器官最多3个

**监控指标**:
- 肿瘤器官计算耗时（目标: <50ms）

## 平衡性测试方案

### 测试方法论

#### 定量测试

**指标定义**:

| 指标 | 测量方式 | 目标值 |

## 游戏阶段平衡性

### 前期平衡性（游戏初期-1小时）

#### 设计目标

**目标**: 肿瘤器官应该是"强力选项"，而非"必需品"

**指标**:
- 使用肿瘤器官 vs 不使用：进度差异<20%
- 玩家满意度：>70%
- 学习曲线：新手能在30分钟内理解基本机制

#### 平衡措施

**良性肿瘤优先**:
- 前期只生成良性肿瘤（胃、肺脏、脾脏）
- 获取难度低（★☆☆☆☆）
- 效果稳定可预测

**搭配简化**:
- 只开放2件套餐
- 相邻搭配效果明显但不极端（+20%）
- 不开放增殖、共生机制

**副作用温和**:
- 良性肿瘤副作用可预测
- 提供清晰的UI提示
- 提供缓解物品（如食物、解毒剂）

### 中期平衡性（1-5小时）

#### 设计目标

**目标**: 提供多样化的Build选择

**指标**:
- 至少3种主流Build
- 不同Build胜率差异<15%
- 玩家尝试至少2种Build

#### 平衡措施

**开放恶性肿瘤**:
- 中期开始掉落恶性肿瘤
- 获取难度中等（★★★☆☆）
- 提供高风险高回报选择

**搭配丰富**:
- 开放4件套餐
- 开放主题搭配
- 开放部分跨系搭配

**增殖机制**:
- 开放基础增殖
- 增殖度上限限制在安全期（<6）
- 增殖概率适中（10-20%）

### 后期平衡性（5+小时）

#### 设计目标

**目标**: 提供极限挑战和深度内容

**指标**:
- 至少5种有效Build
- 极限Build强度达到+150%+
- 技术天花板高

#### 平衡措施

**开放所有机制**:
- 特殊肿瘤获取
- 9件套餐
- 共生机制
- 隐藏搭配

**高风险内容**:
- 9件套餐风险极高
- 增殖失控可能死亡
- 阑尾觉醒失败代价大

**平衡机制**:
- 极端Build伴随极端风险
- 非肿瘤Build依然可行（技巧弥补）
- 提供多种选择而非强制

### 各阶段过渡平衡

#### 从前期到中期

**过渡设计**:
- 玩家首次获得恶性肿瘤时，提供教程
- 肿瘤器官商人出现，提供购买渠道
- 副作用强度逐渐增加

**避免问题**:
- 不要突然增加难度
- 不要突然改变机制
- 不要强制玩家使用恶性肿瘤

#### 从中期到后期

**过渡设计**:
- 玩家首次获得特殊肿瘤时，提供警告
- 高级搭配需要完成挑战才能激活
- 风险和收益同步提升

**避免问题**:
- 不要让非特殊肿瘤Build突然过时
- 不要让某些器官成为必需品
- 不要让游戏变得过于复杂

### Mitigation策略

#### 降低风险的通用策略

**1. 准备充足物品**:
- 食物（应对胃的无尽饥饿）
- 解毒剂（应对毒素层数）
- 抗生素（应对阑尾炎）
- 恢复药水（应对生命流失）

**2. 理解机制**:
- 阅读器官描述
- 了解副作用触发条件
- 理解搭配效果

**3. 渐进尝试**:
- 从良性肿瘤开始
- 逐步尝试恶性肿瘤
- 最后尝试特殊肿瘤

**4. 监控状态**:
- 定期检查胸腔UI
- 注意层数（毒素、废物）
- 注意状态（阑尾炎、代谢）

#### 应对突发情况

**肌肉痉挛**:
- 立即停止攻击和移动
- 等待痉挛结束（1-3秒）
- 避免在关键时刻（如BOSS狂暴）触发

**阑尾炎**:
- 使用抗生素治疗
- 或等待自然结束
- 或手术切除（失去阑尾）

**增殖失控**:
- 立即移除多余器官
- 或使用净化药水
- 避免增殖度达到12+

**毒素/废物层数过高**:
- 使用解毒剂/净化水晶
- 或等待自然清除
- 避免积累层数过高

### 平衡性监控系统

#### 实时监控

```java
public class BalanceMonitor {
    private Map<String, OrganBalanceConfig> organStats;
    private Map<String, SynergyBalanceConfig> synergyStats;
    private List<PlayerBalanceStats> playerStats;

    // 定期更新统计数据
    public void updateStats() {
        for (PlayerBalanceStats player : playerStats) {
            updatePlayerStats(player);
        }
        calculateOrganBalance();
        calculateSynergyBalance();
    }

    // 计算器官平衡性
    private void calculateOrganBalance() {
        for (OrganBalanceConfig organ : organStats.values()) {
            float balanceScore = organ.getPowerLevel() - organ.getRiskLevel();
            organ.setBalanceScore(balanceScore);

            // 检测异常
            if (Math.abs(balanceScore) > 50) {
                notifyImbalance(organ);
            }
        }
    }

    // 检测不平衡
    private void notifyImbalance(OrganBalanceConfig organ) {
        if (organ.getBalanceScore() > 50) {
            log.warn("器官过强: " + organ.getOrganId());
        } else if (organ.getBalanceScore() < -50) {
            log.warn("器官过弱: " + organ.getOrganId());
        }
    }
}
```

6. ✅ **平衡性测试方案**: 定量/定性测试、Alpha/Beta/RC测试
7. ✅ **游戏阶段平衡性**: 前期/中期/后期平衡、过渡设计

10. ✅ **平衡性监控与调整**: 长期监控、调整流程、记录追踪

### 核心平衡机制

**风险-收益曲线**:
- 1-3个肿瘤: 净收益递增（推荐新手）
- 4-6个肿瘤: 净收益持平（推荐进阶）
- 7-9个肿瘤: 净收益递减（高手挑战）

**类型差异**:
- 良性肿瘤: 低风险稳定收益（+20-30%）
- 恶性肿瘤: 高风险高收益（+50-80%，但风险极高）
- 特殊肿瘤: 完全随机（-30%到+100%）

**搭配平衡**:
- 相邻搭配: +20-30%（中等）
- 套装搭配: +30-100%（高但代价高）
- 主题搭配: +30-40%（条件触发）
- 隐藏搭配: +50-200%（极难触发）

### 平衡性目标

| 指标 | 目标 | 当前评估 |
|------|------|----------|

| 类型平衡 | 使用率差异<30% | ✅ 设计合理 |
